# Explorador de alfabetos, cadenas y lenguajes

Programa de consola desarrollado en Python para trabajar con
alfabetos, cadenas y lenguajes finitos.

## Ejecución

python3 explorador_lenguajes.py

## Convenciones

- Cada símbolo del alfabeto ocupa un carácter.
- Los símbolos se introducen separados por comas.
- La cadena vacía se representa en pantalla como ε.
- El lenguaje vacío se representa como ∅.
